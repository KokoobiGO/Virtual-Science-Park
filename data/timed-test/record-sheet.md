# Timed test: record sheet

One sheet per run. A run is one tester doing one task, either by hand or with
the tool. Score the results against `answer-key.md` (confirmed by the team
before the first run).

Use an anonymous label for the tester (P1, P2), never a name.

Open question for the team: in which order does each tester do the tasks? A
tester who does a task by hand and then the same task with the tool already
knows the answers the second time.
